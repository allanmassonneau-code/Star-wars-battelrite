# Star Wars Arena (Battlerite-like)

Jeu d'arène 1v1 en vue 3/4 plongeante (comme Battlerite), jouable directement dans le navigateur : ouvrir `index.html`.

- 3 champions : **Chevalier Jedi** (mêlée, renvoi), **Seigneur Sith** (éclairs, étranglement, drain), **Chasseur de primes** (distance, explosifs, jetpack). L'IA prend un autre champion au hasard.
- Contrôles : ZQSD/WASD ou flèches, souris pour viser, Clic G / Clic D / Espace / Q (A en AZERTY) / E / R (ultime, 100 d'énergie). M coupe le son.
- Incantations avec zone affichée au sol (esquivables), interruptions par étourdissement ou repoussement.
- Holocron de soin au centre après 18 s, mort subite à 45 s : l'arène se referme.
- Au meilleur des 3 manches.
