# Star Wars Arena (Battlerite-like)

Petit jeu d'arène 1v1 en vue du dessus, dans l'esprit de Battlerite, jouable directement dans le navigateur : ouvrir `index.html`.

- Champions : **Jedi** (mêlée, renvoi) ou **Chasseur de primes** (distance, explosifs). L'IA joue l'autre (le Jedi adverse devient un Inquisiteur Sith).
- Contrôles : ZQSD/WASD ou flèches pour bouger, souris pour viser, Clic G / Clic D / Espace / Q (A en AZERTY) / E / R (ultime, coûte 100 d'énergie).
- Au meilleur des 3 manches, holocron de soin au centre après 18 s.
